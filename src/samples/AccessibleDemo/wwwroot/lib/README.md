# Vendored browser assets

These files are served locally; the demo does not load executable scripts from a CDN at runtime.

- Bootstrap 5.3.8: [official release](https://github.com/twbs/bootstrap/releases/tag/v5.3.8), CSS and bundled JavaScript from the tagged `dist` directory. MIT license in `bootstrap/LICENSE`.
- jQuery 3.7.1: [official distribution](https://releases.jquery.com/jquery/), retained for the tree-view example. MIT license in `jquery/LICENSE.txt`.

Only assets used by the demo are included. Source-map comments may refer to optional maps that are not shipped.
